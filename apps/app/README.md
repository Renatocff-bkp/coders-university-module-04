# App cliente (React + Vite)

SPA do cliente da Coders University. Nesta fase entrega a tela de status
operacional consumindo `GET /health` e `GET /api/v1/ping`.

## Comandos

```bash
npm run dev:app   # Vite em http://localhost:3000
npm run dev       # tudo (API + app + docs)
npm run build     # build de produção (dist/)
npm run lint
npm run check-types
npm run test
```
