# Negócio

## Visão

Plataforma de gestão de agentes de IA customizados, especializados em funções executivas específicas.

## Problema

Empresas precisam de análises e tomadas de decisão especializadas por área (CEO, CMO, CTO, etc.), mas contratar especialistas humanos é caro e lento.

## Solução

Agentes de IA que atuam como especialistas em áreas específicas, conectados a fontes de dados externas da empresa para produzir análises, recomendações e ações.

## Personas (Agentes)

| Agente                    | Especialidade                           |
| ------------------------- | --------------------------------------- |
| CEO Expert                | Visão estratégica, negócios, resultados |
| CMO Expert                | Marketing, growth, marca                |
| CTO Expert                | Tecnologia, arquitetura, engenharia     |
| CFO Expert                | Finanças, orçamento, análise financeira |
| COO Expert                | Operações, processos, eficiência        |
| CPO Expert                | Produto, roadmap, valor ao usuário      |
| Sales Director            | Vendas, pipeline, receita               |
| Customer Success Director | Retenção, satisfação, sucesso           |
| Customer Hero Director    | Advocacy e suporte excepcional          |

## Fontes de dados (conectores)

Os agentes consomem dados de ferramentas externas:

- Notion
- Google Drive / Docs / Sheets
- Confluence
- Jira
- ClickUp
- PDF
- TXT
- Markdown
- Imagens (jpg, jpeg, png)
- Vídeos (mp4)
- Áudio (mp3)
- URLs externas
- Linea

## Status atual

Fase inicial — monorepo front-end em estruturação. Os conectores de dados e a lógica dos agentes serão implementados nas próximas fases.
