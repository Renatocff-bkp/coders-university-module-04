# Design

## Princípios

- **Clean** — Interfaces limpas, sem elementos desnecessários.
- **Minimalista** — Apenas o essencial em cada tela.
- **Elegante** — Tipografia refinada, espaçamento generoso, interações sutis.
- **Light theme** — Tema claro exclusivo. Sem suporte a dark mode.

## Tipografia

- **Sans:** Geist Sans (UI, textos)
- **Mono:** Geist Mono (código, dados técnicos)

## Regras

- Contraste mínimo WCAG AA (4.5:1 para texto).
- Bordas suaves (border-radius generoso).
- Sombras leves para elevação.
- Espaçamento consistente (escala de 4px).
